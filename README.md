# 漫行 90+ · 丝路与海风

为 90–99 天跨境长途旅行设计的个人行程规划网站。当前行程为 96 天、19 个停靠点；路线从中国新疆出发，经中亚、高加索、巴尔干、埃及、海湾国家和东南亚，最后回到上海。菲律宾站安排 12 天，以宿务、墨宝和薄荷岛周边海岛潜水为主。

## 功能

- **预算规划**：住宿、餐饮、交通、门票与菲律宾潜水、签证保险、应急金六项独立编辑，默认总额 ¥29,800，并限制在 ¥29,999 以下；自动计算 96 天日均预算并保存在当前设备。建议从体验预算中留出至少 ¥4,300 用于海岛潜水。
- **PDF 行程**：导出包含完整路线、逐日安排、各站停留日期和预算明细的打印版行程。在浏览器打印窗口选择“另存为 PDF”。
- **路线动画**：地图使用每个停靠城市的经纬度投影绘制路线，支持播放、暂停、重置、拖动进度和选择停靠城市。
- **逐国攻略**：19 个路线段、96 天具体安排；每站包含景点顺序、入境/离境衔接、背包客省钱走法、风险提醒和可打开的参考来源。丝路重叠段优先参考 SILKLOOP，其余用官方交通/旅游资料和背包客攻略补齐。核对日期为 2026-10-14。
- **漫行助手**：无密钥时可基于逐国资料回答预算、交通、国家和潜水问题；配置密钥后，Vercel `/api/assistant` 函数在服务端调用 OpenAI Responses API。密钥只从 `OPENAI_API_KEY` 环境变量读取，浏览器和仓库都不包含密钥。

## 本地预览与构建检查

```sh
npm run build
npm start
```

`npm start` 在本机启动无依赖预览服务器，包含 `/api/assistant` 路由。发布到 Vercel 后，原生 Serverless Function 会接管同一 API 路径。

## 启用 AI 助手

在 Vercel 项目中打开 **Settings → Environment Variables**，添加 `OPENAI_API_KEY`，值为你在 OpenAI API Platform 创建的 API key；可选添加 `OPENAI_MODEL`（默认 `gpt-6-luna`）。选择适用的 Preview/Production 环境后保存并重新部署。真实密钥不要写入源码、`.env.example` 或 Git；本地开发请将实际值写在被 Git 忽略的 `.env.local` 中。模型 API 使用可能产生费用，是否启用和账户额度由你在 OpenAI 平台自行决定；本项目未创建密钥、开通账单或购买额度。

AI 回答和逐国资料用于旅行规划，不会查询实时班次、边境状态或签证数据库。缅甸行程标注为条件行程，须核对中国领事提醒、实际航班和保险后再决定；任一不通过就跳过该段。¥29,800 是极限背包规划目标，不代表当前路线一定能按此价格实现。预订前需逐项核实跨境交通、各国签证与潜水保险；潜水活动的承保范围须包含水肺潜水。

## 技术结构

- 原生 HTML、CSS 与浏览器 JavaScript，无前端依赖或构建打包步骤；逐国资料位于 `guides.js`。
- Vercel 托管静态前端，并将 `api/assistant.mjs` 作为 Node.js Web Handler 部署到 `/api/assistant`。
- `npm run build` 检查前端脚本语法、服务端处理器导出、部署配置和四项功能的关键结构。
